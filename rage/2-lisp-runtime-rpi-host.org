* Adversarial review
1. *GPL exposure*: repo had no LICENSE; adapting GPLv3 code makes this a derivative work → add LICENSE (GPL-3.0-or-later) + =:license= in asd. Resolved in scope.
2. *Copy-only duplicate runtime*: extraction is re-authored =star.edge.*= code with provenance headers; downstream forwarding/retirement recorded as follow-up in docs/PROVENANCE.md (server code retires only after consumer equivalence passes there).
3. *Platform string stability*: facade accepts only "linux-rpi" for Linux; laptop profile reuses the same Linux runtime backend rather than inventing a new platform string (contract stability).
4. *Outbox bound policy*: refuse-when-full chosen; drop-oldest silently loses operations. Purge is explicit. fsync before ack; crash-recovery test covers mid-journal kill.
5. *Power honesty*: policy consumes caller-supplied state; /sys backend returns unavailable without battery; no fabricated values.
6. *Nix untrusted-user limits*: checks use import-level system overrides (no =--system= flag); aarch64 = eval + cross/substitute; uncached aarch64 builds are NOT attempted locally — recorded, not hidden.
7. *CI sbcl lacks sento*: workflow must install quicklisp+sento before the Lisp gate; otherwise exact-head CI goes red.
8. *Signal handlers under --script*: bounded install pattern copied from proven server semantics; safe non-interactively.
9. *Secrets*: none copied; PROVENANCE records excluded private paths; NixOS module takes no secret values.
